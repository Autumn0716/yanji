### 复习要点

知识笔记：[计算机系统概述](../../../vault/408/计算机组成原理/系统概述.md)

#### 重点考点

- 冯·诺依曼思想：存储程序、指令与数据同存、二进制表示、五大部件。
- CPU 时间公式：`CPU时间 = 指令数 × CPI / 主频`；时钟周期、主频、CPI、IPC 的关系。
- 吞吐率、响应时间、加速比；Amdahl 定律对局部优化上限的约束。
- 编译器、ISA、微体系结构和数字逻辑的层次关系。

#### 难点

- 主频提高不保证程序更快；指令数和 CPI 可能同时变化。
- MIPS 不能跨不同 ISA 或不同指令混合直接比较。
- Amdahl 定律必须按原运行时间占比计算可优化部分。

#### 易错点

- 把时钟周期与机器周期、指令周期混为一谈。
- 用“主频最高”直接推出“性能最好”。
- CPI 是每条指令平均时钟周期，不是每秒指令数。

### 复习要点

知识笔记：[逻辑与数据运算](../../../vault/408/计算机组成原理/逻辑数字运算.md)

#### 重点考点

- 无符号数、原码、反码、补码、移码；表示范围与符号扩展。
- 定点加减法、溢出判断、进位与溢出的区别；加法器结构与标志位。
- 乘除运算基本原理；阵列乘法器、恢复余数/不恢复余数思想。
- IEEE 754 单精度/双精度：规格化数、非规格化数、±0、±∞、NaN。
- 大端/小端、边界对齐、C 语言类型转换与位级结果。

#### 难点

- 补码加减中“丢弃最高进位”与“有符号溢出”是两件事。
- 浮点加减的对阶、尾数运算、规格化、舍入和溢出流程。
- 有符号与无符号混合比较时，整型提升和转换会改变解释方式。

#### 易错点

- `n` 位补码范围写成 `[-2^n, 2^n-1]`；正确是 `[-2^(n-1), 2^(n-1)-1]`。
- 用最高位进位判断有符号溢出；应看同号相加结果异号，或符号位进位异或。
- 把浮点机器数直接按十进制有效位数理解，忽略二进制舍入。
- 小端只改变多字节对象在内存中的字节次序，不改变位权和寄存器数值。

- Cache 地址划分：块内偏移、组索引、标记；直接/全相联/组相联映射。
- 替换策略与写策略：LRU/FIFO/随机，写直达/写回，写分配/非写分配。
- 虚拟地址到物理地址：页号、页内偏移、TLB、页表、缺页；Cache 与页式虚存协同。
- 磁盘、RAID、SSD 的基本组织、性能与可靠性权衡。

#### 难点

- 同一地址需依次经过 TLB、页表和 Cache；每层切分字段的对象不同。
- Cache 缺失与缺页不是同一层故障；处理代价和执行主体不同。
- 多体交叉存储器连续访问的吞吐率受体数、模块周期和总线节拍共同影响。
- AMAT 递归计算时，每一级缺失代价是否包含下一级命中时间要按题目定义。

#### 易错点

- Cache 块大小与主存块大小应一致；组号位数由组数决定，不由总行数直接决定。
- 写回法的脏位表示该块已被 CPU 修改且尚未同步到下层。
- 页表项中的物理页框号不能与虚页号直接拼接；只有页内偏移原样保留。
- RAID 0 提高性能但不提供冗余；RAID 1 容量利用率通常约 50%。

- 单总线数据通路同一时刻只能有一个源驱动总线，复杂操作需分多个节拍。

#### 易错点

- IR 存当前指令，PC 通常已指向下一条指令；二者职责不同。
- MAR/MDR 常位于存储器接口，位数分别与地址字长/存储字长相关。
- “一条机器指令对应一条微指令”错误；通常对应一段微程序。
- 异常和中断都能改变控制流，但内部/外部来源与同步性不同。


### 复习要点

知识笔记：[流水线与异常](../../../vault/408/计算机组成原理/CPU/流水线与异常.md)

#### 重点考点

- 流水线吞吐率、加速比、效率；理想 `k` 级流水线完成 `n` 条指令所需时间。
- 结构、数据、控制冒险；暂停、转发、分支预测和延迟槽的基本思想。
- RAW/WAR/WAW 相关；经典顺序五级流水线主要关注 RAW。
- 超标量与基本动态调度概念；SIMD/向量处理与数据级并行。

#### 难点

- 有转发也不一定消除 load-use 冒险，数据可用时刻晚于下一条所需时刻。
- 分支罚时取决于分支解析级、预测策略和冲刷流水级数。
- 画时空图时必须区分“停顿某条指令”和“冻结前级寄存器”。

#### 易错点

- 把流水线提高吞吐率说成必然缩短单条指令延迟。
- 理想完成时间漏掉装入阶段，写成 `nT` 而非 `(k+n-1)T`。
- 把寄存器同名都当成相关；只有存在读写依赖才构成数据相关。

- 总线组成、带宽、同步/异步定时、突发传输、仲裁。
- I/O 编址、程序查询、中断驱动、DMA；CPU、设备与主存间数据流。
- 中断优先级、屏蔽字、中断嵌套；DMA 周期挪用与总线争用。
- 多处理器基本概念：SISD/SIMD/MIMD、共享内存、Cache 一致性概念。

#### 难点

- 总线带宽需明确每次传输字节数、总线频率及每次传输占用周期数。
- 中断响应时刻、现场保存范围和允许嵌套条件由题设架构决定。
- DMA 只替代成块数据搬运，不负责整个 I/O 请求的所有控制逻辑。

#### 易错点

- 中断向量是入口地址或其索引，不等同于中断服务程序本体。
- DMA 与 CPU 仍可能争用内存总线；不是完全并行互不影响。
- 异步总线没有统一时钟，不代表没有握手时序约束。
- Cache 一致性问题来自多副本可写；与单核局部性的命中率问题不同。

## 全科针对性练习

### 针对性选择题（原创）

#### 1. CPU 性能

某程序动态执行 `10^9` 条指令，平均 CPI 为 1.5，主频为 3 GHz。忽略其他因素，CPU 时间为：

A. 0.25 s  B. 0.5 s  C. 1.5 s  D. 2 s

**答案：B。** `10^9 × 1.5 / (3×10^9)=0.5 s`。

#### 2. 补码溢出

8 位补码 `01111111 + 00000001` 的结果与状态是：

A. `10000000`，无溢出  B. `10000000`，溢出  C. `00000000`，进位  D. `11111111`，溢出

**答案：B。** 两个正数相加得到负号结果，发生有符号溢出。

#### 3. IEEE 754

单精度浮点数的阶码字段全 1、尾数字段非 0 表示：

A. 零  B. 非规格化数  C. 无穷大  D. NaN

**答案：D。** 阶码全 1 且尾数为 0 才表示无穷大。

#### 4. Cache 地址划分

32 位按字节编址机器，Cache 容量 32 KiB，块大小 64 B，4 路组相联。组索引位数是：

A. 5  B. 7  C. 9  D. 11

**答案：B。** 行数 `32768/64=512`，组数 `512/4=128`，需 7 位。

#### 5. 虚拟存储

地址转换过程中始终不变的是：

A. 虚页号  B. 页框号  C. 页内偏移  D. TLB 索引

**答案：C。** 页式转换把虚页号映射为页框号，页内偏移原样保留。

#### 6. 数据通路

在单总线 CPU 中，一条微操作不能让两个源寄存器同时直接驱动总线，主要原因是：

A. 寄存器太慢  B. 总线冲突  C. ALU 不能加法  D. IR 未就绪

**答案：B。** 同一时刻多个源驱动会产生电气与逻辑冲突。

#### 7. 流水线

经典五级顺序流水线有完整转发时，紧邻的 load-use 相关通常仍需停顿，原因是：

A. 取指失败  B. load 数据产生过晚  C. 存在 WAW  D. 分支预测错误

**答案：B。** 访存数据在 MEM 末尾才可用，下一条 EX 所需时间更早。

#### 8. I/O

最适合大块高速数据传输、显著减少 CPU 逐字干预的是：

A. 程序查询  B. 中断驱动  C. DMA  D. 陷阱

**答案：C。** CPU 负责初始化，DMA 控制器成块搬运并在完成后通知。

### 针对性综合题（原创）

#### 综合题 1：Cache 访问序列

**题目：** 16 位按字节编址，Cache 数据区 128 B，块大小 16 B，2 路组相联，初始为空，**同组明确采用 LRU（不是 FIFO）**。依次访问地址（十进制）：`0, 16, 64, 0, 128, 64, 128`。写出每次命中/缺失，并给出最终各组中的主存块号。

**参考答案：**

- Cache 行数 `128/16=8`，组数 `8/2=4`。
- 主存块号依次：`0,1,4,0,8,4,8`；组号为块号模 4：`0,1,0,0,0,0,0`。
- 访问结果：`M, M, M, H, M, M, H`。
- 第 0 组 LRU 过程：`0` → `0,4` → 访问 `0` 后 `4,0` → 装入 `8` 淘汰 `4`，得 `0,8` → 装入 `4` 淘汰 `0`，得 `8,4` → 访问 `8` 命中。
- 最终：第 0 组块 `8,4`；第 1 组块 `1`；其余为空。

#### 综合题 2：页表、TLB 与 Cache

**题目：** 32 位虚拟地址，页大小 4 KiB；物理内存按字节编址。TLB 命中时间 1 ns，主存访问 80 ns；页表在主存，忽略 Cache。假设 TLB 命中率 95%，无缺页，TLB 与主存串行访问。求一次访存的平均时间。

**参考答案：**

- TLB 命中：查 TLB 1 ns + 访问数据 80 ns = 81 ns。
- TLB 未命中：查 TLB 1 ns + 访问页表 80 ns + 访问数据 80 ns = 161 ns。
- 平均：`0.95×81 + 0.05×161 = 85 ns`。
- 若题目规定 TLB 与 Cache 并行或页表多级，公式必须相应改变。

#### 综合题 3：五级流水线

**题目：** 五级流水线 `IF-ID-EX-MEM-WB`，完整转发，分支在 EX 末判定且采用预测不跳转；load-use 冒险停 1 个周期。指令序列：

```asm
I1: LW  R1, 0(R2)
I2: ADD R3, R1, R4
I3: SUB R5, R3, R6
I4: BEQ R5, R0, L   # 实际跳转
```

计算完成到正确路径开始取指前产生的停顿/冲刷周期总数（不计流水线装入与排空）。

**参考答案：**

- `I1→I2` 为 load-use，停 1 周期。
- `I2→I3`、`I3→I4` 可通过转发解决，无额外停顿。
- 分支在 EX 末判定，预测错误时错误路径中已有 IF、ID 两条指令，冲刷 2 个周期。
- 总损失 `1+2=3` 个周期。

#### 综合题 4：DMA 与 CPU 争用

**题目：** 某 DMA 每传一个 4 B 字占用主存总线 1 个周期，总线频率 100 MHz。若 DMA 以周期挪用方式连续传输 1 MiB 数据，理论总线占用时间是多少？若 CPU 原本每 5 个周期平均需要一次主存访问，说明性能影响。

**参考答案：**

- 字数：`2^20 / 4 = 2^18 = 262144`。
- 每周期 10 ns，占用时间 `262144×10 ns ≈ 2.62144 ms`。
- 连续周期挪用期间总线被 DMA 占用，CPU 的主存访问需等待；纯寄存器/Cache 命中操作仍可能执行，具体停顿取决于缓冲和仲裁。不能简单说 CPU 完全停止或完全不受影响。

### 完成标准

- 能从 C/汇编/地址序列一路推到寄存器、主存、Cache/TLB 状态。
- 数值题必须先写单位与假设，再代公式。
- 数据通路题明确“哪个部件在何时读/写什么”。
- 流水线题必须画时空关系或逐周期表，不能只凭结论猜停顿数。
