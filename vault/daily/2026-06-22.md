### 🌐 网络与访问

- **APP_URL 不用 `127.0.0.1` 的原因**：`127.0.0.1` 语境不同含义不同——容器里指容器自己，浏览器里指用户本机。APP_URL 是给"对外"用的（回调、CSP、外部访问），必须填真实 IP 或域名。服务监听同理：绑 `0.0.0.0` 才是全网可访问，绑 `127.0.0.1` 只本机能连。
- **Tailscale**：基于 WireGuard 的零配置组网。同账号登录后设备互通，每台分到 `100.x.x.x` IP，自动 P2P 打洞。默认**只对内网设备可见**，公网访问要开 Funnel。
- **Docker 权限**：`sudo usermod -aG docker $USER && newgrp docker`。⚠️ 能跑 docker ≈ 能 root,生产环境别给普通用户。
- **镜像拉不到**:两条路叠加——① `/etc/docker/daemon.json` 加 `registry-mirrors`(源失效快,搜「docker 镜像加速 2026」);② systemd drop-in 配 `HTTP_PROXY/HTTPS_PROXY`。
- **Tailscale 打不开端口**排查顺序:服务监听 `0.0.0.0`(`ss -tlnp | grep 端口`)→ Docker `-p` 映射(`docker ps` 看 PORTS)→ 防火墙(`ufw allow`)→ Tailscale ACL → `tailscale ping` + `curl -v` 区分网络层/应用层问题。

### 🏗️ 自部署

- **Arcane**:Docker 容器管理 Web UI,Portainer 的轻量替代。`docker run -d -p 8000:8000 -v /var/run/docker.sock:/var/run/docker.sock -v arcane_data:/data ghcr.io/ofkm/arcane:latest`,浏览器 `:8000`。
- **同类推荐**:Nginx Proxy Manager(反代+HTTPS 可视化)、AdGuard Home(去广告 DNS)、Vaultwarden(密码库)、Immich(照片云)、Jellyfin(媒体)、AList(网盘聚合)、Homepage(导航首页)、Uptime Kuma(监控)。
- **Nginx**:Web 服务器 + 反向代理。价值在于统一入口(80/443 按域名分发到几十个服务)+ HTTPS 卸载 + 负载均衡/缓存/限流。新手用 Nginx Proxy Manager 免手写配置。
- **反代 + HTTPS + Tailscale Funnel 关系**:三者解决不同问题。
    - 纯内网(Tailscale 设备互访):什么都不用配,Tailscale 自身已加密
    - 公网正式服务:Nginx/Caddy 反代 + Let's Encrypt 证书
    - 无公网 IP 或临时分享:`tailscale funnel 端口` 一条命令,自动给 `https://机器名.尾巴网.ts.net` 域名+证书

### 🔍 pansou 排错

> 关键:pansou 有**两个镜像**,端口含义不同
> - `ghcr.io/fish2018/pansou-web` → 端口 **80**,前后端集成版,**带 UI**
> - `ghcr.io/fish2018/pansou` → 端口 **8888**,纯 API,**无 UI**

- **80 端口被占**:`sudo lsof -i :80` 查元凶(常是 nginx/CasaOS/1Panel)→ ① 换端口 `-p 8080:80` ② 停掉占用方 ③ 反代统一管(长期最优)。
- **8888 返回 404**:拉错镜像了。纯 API 版没有页面,访问根路径自然 404。`curl localhost:8888/api/health` 能返回 JSON 就说明服务正常。要 UI 换 `pansou-web`。

### 🧲 磁力链接

- `magnet:?xt=...` 是内容指纹,靠 P2P 网络,不指向任何服务器。
- 客户端首推 **qBittorrent**(开源无广告,支持 Web UI 远程):复制链接 → 文件 → 添加种子链接。
- 下不动常见原因:没人做种(资源已死)/ 缺 trackers(GitHub 搜 `ngosang/trackerslist`)/ 运营商封 BT(用 VPN 或代理)。
- 配合 pansou:搜出磁力 → 复制 → 丢给 qBittorrent。
