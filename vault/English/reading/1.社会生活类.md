# 阅读心得

1. steady本身是负面词性,but已经恢复其语义,所以这里的单词应该是 **成功+快速&#x20;**

`What some scientists hoped would be a blitzkrieg has turned out to be a steady but sure fight.`

steady but sure 这里steady应该与前面单词有相反的意思,所以肯定是 *==快速的==&#x20;*这种单词的意思;
