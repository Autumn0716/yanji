# 大模型训练与微调(生命周期枢纽)

> [!abstract] 一句话
> LLM 的一生:**预训练(学语言)→ SFT(学听话)→ 对齐(学价值观)→ 量化/部署(上线)**。训练阶段的选择直接决定推理形态(GQA/MoE/上下文长度都是训练时定的)。推理侧见 [大模型推理与部署](./大模型推理与部署.md)。

---

## 1. 生命周期总览
```
海量无标注语料 ──预训练(自监督, next-token)──► 基座模型(base)
      │  目标:压缩世界知识,~6N FLOPs/token
      ▼
指令数据 ──SFT(监督微调)──► 会跟随指令的模型(instruct)
      ▼
偏好数据 ──对齐(RLHF / DPO)──► 符合人类偏好/安全的模型(chat)
      ▼
量化/蒸馏 ──部署──► 上线推理(见推理簇)
```

## 2. 各阶段一览
| 阶段 | 数据 | 目标 | 算力 | 详见 |
|---|---|---|---|---|
| **预训练** | TB 级无标注 | 学知识/语言 | 最大(数千卡月) | [预训练与 Scaling Law](./预训练与 Scaling Law.md) |
| **SFT** | 万~百万指令对 | 学格式/听话 | 中 | 本页 §3 |
| **对齐** | 偏好对(chosen/rejected) | 学偏好/安全 | 中 | [RLHF DPO PPO](./RLHF DPO PPO.md) |
| **参数高效微调** | 任务数据 | 低成本定制 | 小 | [LoRA 与 QLoRA](./LoRA 与 QLoRA.md) |

## 3. SFT(监督微调 / 指令微调)
- 数据:`(instruction, response)` 对,套 **chat template**(角色标记)。
- 损失:只对 **response 部分**算 cross-entropy(mask 掉 prompt)。
- **Packing**:多条短样本拼到一个序列填满上下文,提训练效率(注意 attention mask 隔离)。
- 全参 SFT 成本高 → 多用 [LoRA 与 QLoRA](./LoRA 与 QLoRA.md)。

## 4. 训练的工程支柱
- **优化器与稳定性**:AdamW、warmup、混合精度、梯度检查点 → [优化器与训练稳定性](./优化器与训练稳定性.md)
- **分布式**:DP/TP/PP + ZeRO/FSDP → [训练并行 FSDP ZeRO](./训练并行 FSDP ZeRO.md) / [分布式训练与并行](./分布式训练与并行.md)
- **算力账**:训练 ~6N FLOPs/token(推理 2N),见 [预训练与 Scaling Law](./预训练与 Scaling Law.md)

## 5. 训练 ↔ 推理的桥
| 训练时决定 | 影响推理 |
|---|---|
| GQA/MQA 头数 | KV Cache 大小 |
| MoE 专家数 | 显存/算力解耦([MoE 混合专家](./MoE 混合专家.md)) |
| 上下文长度 + RoPE base | 外推能力([RoPE 数学推导](./题型精讲/RoPE 数学推导.md)) |
| 是否 QAT | 量化精度([模型量化](./模型量化.md)) |
