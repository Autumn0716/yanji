# 分布式训练与并行

> [!abstract] 一句话
> 模型/数据装不下单卡时,沿不同维度切分到多卡:**数据(DP)、张量(TP)、流水(PP)、序列(SP)、专家(EP)、上下文(CP)**。推理与训练侧重不同——推理更怕通信延迟。主线见 [大模型推理与部署](./大模型推理与部署.md)。

---

## 1. 六种并行一览
| 并行 | 切什么 | 通信 | 推理要点 |
|---|---|---|---|
| **DP** 数据 | 复制整模型,分发不同 batch | 梯度 AllReduce(训练) | 推理=多副本横向扩容 |
| **TP** 张量 | 层内权重矩阵(列切+行切配对) | 每层 AllReduce | **RMSNorm 复制不切**;≤8 卡(NVLink) |
| **PP** 流水 | 按 layer/stage | 跨 stage P2P | Bubble 空闲;需 micro-batch |
| **SP** 序列 | LayerNorm/Dropout 等沿序列激活 | AllGather/ReduceScatter | 降长序列激活显存 |
| **EP** 专家 | MoE 专家分卡 | **all-to-all** | 路由瓶颈,见 [MoE 混合专家](./MoE 混合专家.md) |
| **CP** 上下文 | 超长序列沿序列维(Ring Attention) | 环形 KV 传递 | 百万级上下文 |

## 2. TP 细节(最常用)
- **列并行**:$Y=XW$ 把 $W$ 按列切,各卡算部分输出 → AllGather 拼。
- **行并行**:$W$ 按行切,各卡算部分和 → AllReduce 求和。
- Attention:QKV 列并行、O 行并行,配对后每层 **2 次 AllReduce**(attn 后 + FFN 后)。
- **不切**:RMSNorm/LayerNorm 复制到每 rank;Embedding/LM Head 按词表维切(vocab parallel)。
> [!warning] 经典错项
> "TP 所有层都切、无复制层" = 错;RMSNorm 每 rank 复制(见 [大模型推理与部署](./大模型推理与部署.md) §VII.3)。

## 3. PP 细节
按层切成 stage 流水。**Bubble**(流水填充/排空的空闲)是主损耗,用 micro-batch(GPipe / 1F1B 调度)摊薄。推理低并发时 Bubble 占比高 → 效率差。

## 4. 通信原语
- **AllReduce = ReduceScatter + AllGather**;**Ring AllReduce** 带宽最优,传输 $2\frac{N-1}{N}\times$ 数据,与卡数近似无关。
- **小消息延迟受限 / 大消息带宽受限**:Decode 的 TP 是小消息 → 延迟敏感,**NVLink(600GB/s 低延迟)≫ PCIe**。
- **all-to-all**:EP 路由 token 的主要开销。
- 库:**NCCL**。

## 5. 训练 vs 推理侧重
| | 训练 | 推理 |
|---|---|---|
| 显存压力 | 权重+梯度+优化器状态+激活 | 权重 + KV |
| 主并行 | DP+TP+PP(3D)+ ZeRO | TP(+PP) |
| 通信痛点 | 梯度 AllReduce 带宽 | 每步 AllReduce **延迟** |

> **ZeRO**(DeepSpeed):把优化器状态/梯度/参数分片到 DP 各卡,消除冗余,训练省显存的主力(推理用处小,因推理无优化器状态)。
