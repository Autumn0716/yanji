# 大模型推理与部署 · 期末试卷与答案

> [!info] 说明
> 满分 150 / 时长 150 分钟。三大题 24 小题。原始 PDF 见同目录 [PDF: 期末试卷.pdf](../试题/大模型推理与部署_期末试卷.pdf)、[PDF: 参考答案.pdf](../试题/大模型推理与部署_参考答案.pdf)。解答题完整推导见本文件夹各「题型精讲」笔记。
> 默认约定:自注意力维度 $d$、序列长 $n$ 或 $L$、头数 $h$、$d_h=d/h$、batch $B$、词表 $V$、KV Cache fp16。

## 一、选择题(12×5 = 60 分)

> [!success] 答案速查
> **1.B 2.C 3.B 4.D 5.B 6.D 7.B 8.B 9.B 10.C 11.B 12.D**

**1.** 标准 Self-Attention 单层前向中,注意力计算部分($QK^\top$ 与 $\text{softmax}(QK^\top)V$)的时间复杂度为
→ **B. $O(n^2d)$** ｜ $QK^\top$ 形状 $n\times n$、每元素 $d$ 次乘加;A=单头某步,C=线性层,D=极端误估。

**2.** 关于 KV Cache 的作用,正确的是
→ **C. KV Cache 是自回归解码时降低每步时间复杂度从 $O(n^2d)$ 到 $O(nd)$ 的关键** ｜ 详见 [KV Cache 与 FLOPs 推导](./KV Cache 与 FLOPs 推导.md)。

**3.** $h{=}32,d_h{=}128,L{=}2048$,MHA/MQA/GQA($G{=}8$)单条请求 Decode 每步 KV 读取量关系
→ **B. MHA > GQA > MQA 且 GQA 介于二者之间** ｜ $2Lh_{KV}d_h{\cdot}2$,$h_{KV}$ 越大越多。

**4.** RoPE 相对绝对正弦编码的优势,**错误**的是
→ **D.「RoPE 使注意力复杂度从 $O(n^2d)$ 升至 $O(n^3)$」** ｜ RoPE 仅旋转 $Q,K$,仍 $O(nd)$。见 [RoPE 数学推导](./RoPE 数学推导.md)。

**5.** Prefill 与 Decode 的计算特性
→ **B. Prefill 通常 Compute-bound,Decode 通常 Memory-bound** ｜ 算术强度分析见 [大模型推理与部署](../大模型推理与部署.md) §I.3。

**6.** PagedAttention 主要解决的显存问题**不包括**
→ **D. Decode 阶段每步矩阵乘法的算子融合效率** ｜ 它治内/外碎片 + 预分配浪费,不管融合。

**7.** Static / Continuous / In-flight Batching,**正确**的是
→ **B. Continuous Batching 允许在任意 token 边界插入新请求、踢出已完成请求** ｜ In-flight 是 TRT-LLM 实现名,非完全等价。

**8.** GPTQ / AWQ / SmoothQuant 核心思想匹配,**正确**的是
→ **B. GPTQ 基于 Hessian;AWQ 基于显著通道缩放;SmoothQuant 基于激活平滑迁移** ｜ 三者皆 PTQ。见 [模型量化](../模型量化.md)。

**9.** Activation 比 Weight 更难量化的根本原因,**最准确**
→ **B. 激活值在少数通道存在显著离群点(Outlier),致整体量化误差被少数通道主导**。

**10.** Speculative Decoding「草稿—验证」机制,**正确**数学结论
→ **C. 草稿 $q$ 与目标 $p$ 不一致时,通过拒绝采样与重新归一化,最终输出严格服从 $p$** ｜ 见 [Speculative Decoding 证明](./Speculative Decoding 证明.md)。

**11.** FlashAttention 的 IO 复杂度($N,d,M{=}$SRAM)
→ **B. $O(N^2d^2/M)$,长序列时显著低于标准 $O(N^2{+}Nd)$** ｜ 见 [FlashAttention 推导](./FlashAttention 推导.md)。

**12.** TP/PP/SP 在**推理场景**的应用,**错误**的是
→ **D.「TP 在所有层(含 LayerNorm/Embedding/LM Head)都切、无复制层」** ｜ RMSNorm 被复制。见 [分布式训练与并行](../分布式训练与并行.md)。

## 二、填空题(6×5 = 30 分)

**13.** $QK^\top$ 前向时间复杂度 ＿、空间复杂度 ＿
→ **$O(n^2d)$** ；**$O(n^2)$**(分数矩阵 $n\times n$)

**14.** $L{=}32,h{=}32,d_h{=}128$,MHA+fp16,$n{=}4096$ 完整 KV Cache($2^k$)
→ $2\times32\times4096\times32\times128\times2=\boxed{2^{36}\text{ B}=64\text{ GB}}$

**15.** GQA $h{=}40$、$h_{KV}{=}8$,每 KV 头被 ＿ 个 Query 头共享;$h_{KV}{=}$＿ 时退化 MQA
→ **$40/8=5$** ；**$1$**

**16.** Top-p 核集 $V_p=$＿;之后归一化概率 ＿
→ $V_p=\min\{k\mid\sum_{i=1}^k p_i\ge p\}$ ；$p_i/\sum_{w_j\in V_p}p_j$。见 [采样与解码策略](../采样与解码策略.md)。

**17.** RoPE 分块对角矩阵 $R_m=$＿,使 $\langle R_m\mathbf q,R_n\mathbf k\rangle$ 仅依赖 ＿
→ $R_m=\text{diag}\big(\begin{smallmatrix}\cos m\theta_0&-\sin m\theta_0\\\sin m\theta_0&\cos m\theta_0\end{smallmatrix},\dots\big)$ ；相对位置 **$m-n$**

**18.** Spec 草稿一次 $k$ 个、独立接受率 $\alpha$,期望接受 ＿;稳定得 2 个($k{=}4$)需 $\alpha\ge$＿
→ $\sum_{i=1}^k\alpha^i=\dfrac{\alpha(1-\alpha^k)}{1-\alpha}$ ；**$\alpha\ge0.54$**

## 三、解答题(6×10 = 60 分)

每题给答案要点 + 跳转完整推导。

**19.(10 分)KV Cache 必要性**
不用 KV:重算前 $n{+}1$ 位置 $K,V$ → 单步 $O(n^2d)$;用 KV:只算 $q_{n+1}$ → $O(nd)$,降 $n$ 倍;显存 $2Lnh_{KV}d_h b\,B$,算术强度 $\sim1/d_h$ ⇒ Memory-bound。
→ 完整:[KV Cache 与 FLOPs 推导](./KV Cache 与 FLOPs 推导.md)

**20.(10 分)RoPE 数学**
$\langle R_mq,R_nk\rangle=\sum_i q_i^\top R_{(n-m),i}k_i$ 只依赖 $m{-}n$(旋转群 $R_m^\top R_n{=}R_{n-m}$);NTK-aware 改基底,高频不缩、低频缩。
→ 完整:[RoPE 数学推导](./RoPE 数学推导.md)

**21.(10 分)FlashAttention**
标准 HBM $O(n^2{+}nd)$;Tiling + online softmax($m,\ell,\tilde O$ 三式 rescale,$S,P$ 不落盘);Recomputation 反向重算,IO 仍 $O(N^2d^2/M)$,以算代存。
→ 完整:[FlashAttention 推导](./FlashAttention 推导.md)

**22.(10 分)SmoothQuant 等价变换**
$XW=(XS)(S^{-1}W)$,$s_j=c_j^\alpha/w_j^{1-\alpha}$;$\alpha$ 控制激活↔权重迁移强度;把难量化激活转为易量化 → W8A8。
→ 完整:[模型量化](../模型量化.md) §4.3

**23.(10 分)Speculative Decoding**
接受 $r_i=\min(1,p/q)$,拒绝重采样 $(p-q)^+/Z$;证 $P(\text{out}{=}x)=\min(q,p)+(p-q)^+=p(x)$,严格无损;加速比 $\frac{\alpha(1-\alpha^k)}{1-\alpha}\cdot\frac{t_v}{t_d+t_v}$。
→ 完整:[Speculative Decoding 证明](./Speculative Decoding 证明.md)

**24.(10 分,压轴)系统级综合优化**
(a) 长 Prefill 致 P99 毛刺 → Chunked Prefill;(b) SM 仅 45% → 加并发/GQA/Chunked/CUDA Graph/Prefix Caching;(c) 128k OOM → PagedAttention + KV Offloading + Prefix Caching 三级存储(单 token KV≈2.6MB,128k≈332GB)。
→ 完整:[大模型推理与部署](../大模型推理与部署.md) §VIII + [PD 分离与服务工程](../PD 分离与服务工程.md) + [长上下文推理](../长上下文推理.md)
