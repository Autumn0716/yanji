# 投机解码进阶(免草稿模型 + 树验证)

> [!abstract] 一句话
> 经典投机解码需要一个独立小草稿模型(见 [Speculative Decoding 证明](./题型精讲/Speculative Decoding 证明.md))。进阶方向是**去掉独立草稿模型**(自身预测草稿)和**一轮验证多条候选**(树注意力),提升接受率与并行度。主线见 [大模型推理与部署](./大模型推理与部署.md) §VI.1。

---

## 1. 回顾痛点
独立草稿模型有两个成本:① 要额外训练/部署一个对齐良好的小模型;② 草稿与目标分布差异大时接受率低、白跑。进阶方法围绕这两点改进。

## 2. Medusa —— 多预测头
在目标模型最后一层并接**多个预测头**,一次前向同时预测未来第 1、2、3… 个 token 的候选。
- 无需独立草稿模型(头很轻,微调即可)。
- 多头产出**多个候选组合 → 树**,配合树注意力一次验证。

## 3. EAGLE —— 特征层自回归草稿
在目标模型的**特征(倒数第二层 hidden)层**做自回归,而非在 token 层。
- 特征比 token 信息更丰富 → 草稿质量高 → **接受率显著高于普通草稿模型**。
- EAGLE-2/3 进一步用动态草稿树 + 上下文感知,是当前 **SOTA** 方向。

## 4. Lookahead Decoding —— 无模型 n-gram
用**雅可比迭代**并行猜多个位置,同时维护 n-gram 池做候选,无需任何额外模型/训练。对重复性强的文本(代码)收益好。

## 5. 树注意力(Tree Attention)
草稿不再是一条链,而是**一棵候选树**(每步多个分支)。用特制的树形 attention mask,目标模型**一次前向验证整棵树**,接受沿树的最长合法路径 → 每轮期望接受 token 数更高。

## 6. 自草稿(Self-Speculative)
同一模型**跳过部分层**当草稿(浅层快、全层验证),零额外参数。

## 7. 对比
| 方法 | 要独立模型? | 接受率 | 备注 |
|---|---|---|---|
| 经典草稿 | 是 | 中 | 需对齐小模型 |
| Medusa | 否(加头) | 中高 | 多头 + 树 |
| **EAGLE** | 否(特征层) | **高** | SOTA |
| Lookahead | 否 | 中(看文本) | 无训练 |
| Self-Spec | 否(跳层) | 中 | 零参数 |

> 全部沿用 [拒绝采样](./题型精讲/Speculative Decoding 证明.md) → **输出分布严格无损**,只影响速度。
