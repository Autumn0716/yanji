# 注意力机制(Attention)

> [!abstract] 一句话
> 注意力 = 用 Query 去和所有 Key 算相似度,softmax 成权重,对 Value 加权求和。它是 Transformer 的算力/显存双瓶颈来源:时间 $O(n^2d)$、KV Cache 随 $n$ 线性涨。部署视角见 [大模型推理与部署](./大模型推理与部署.md)。

---

## 1. Scaled Dot-Product Attention
$$\text{Attn}(Q,K,V)=\text{softmax}\!\Big(\frac{QK^\top}{\sqrt{d_h}}\Big)V$$
- $\sqrt{d_h}$ 缩放:防点积随维度增大而方差爆炸,使 softmax 不进饱和区(梯度消失)。
- 复杂度:$QK^\top$ 时间 $O(n^2d)$、空间 $O(n^2)$;$PV$ 同阶。
- **Causal Mask**:decoder 自回归,$j>i$ 的位置置 $-\infty$,保证只看历史。

## 2. Multi-Head(MHA)
把 $d$ 切成 $h$ 个 $d_h=d/h$ 的子空间并行做注意力再拼接:
$$\text{MHA}=\text{Concat}(\text{head}_1..\text{head}_h)W^O,\quad \text{head}_i=\text{Attn}(QW_i^Q,KW_i^K,VW_i^V)$$
直觉:不同头学不同关系(语法/指代/位置…),多子空间表达更强。

## 3. KV 头共享:MHA / GQA / MQA / MLA
| 方案 | KV 头 | KV Cache | 质量 |
|---|---|---|---|
| MHA | $h$ | 最大 | 基线 |
| GQA | $h_{KV}$ | 中 | 折中(Llama2/3-70B) |
| MQA | 1 | 最小 | 略降 |
| MLA | 低秩 latent | 最小+ | 近 MHA(DeepSeek) |
- 每 KV 头被 $h/h_{KV}$ 个 Q 头共享;$h_{KV}{=}1$→MQA,$=h$→MHA;GQA 连续插值。
- **MLA**:KV 压成低秩向量存 Cache,用时上投影还原;RoPE 维度解耦。详见 [大模型推理与部署](./大模型推理与部署.md) §II.2。

## 4. 位置编码
- **绝对(正弦/可学习)**:外推差。
- **RoPE(旋转)**:对 $Q,K$ 旋转,内积只依赖相对位置 $m-n$(旋转群 $R_m^\top R_n=R_{n-m}$),零额外算力,不动 $V$。长度外推:PI / NTK-aware(高频不缩低频缩)/ YaRN。
- **ALiBi**:给注意力分数加线性距离偏置 $-\lambda|i-j|$,天然外推。
- **StreamingLLM**:attention sink(前几 token 吸权重)+ 滑窗,无限流式。

## 5. 高效注意力变体
| 变体 | 思想 | 复杂度/KV |
|---|---|---|
| **FlashAttention** | tiling + online softmax,不落盘 $S,P$ | 时间不变,IO $O(N^2d^2/M)$ |
| **Sliding Window**(Mistral) | 只看最近 $W$ | KV 封顶 $W$ |
| **Sparse/Dilated** | 固定稀疏模式 | $O(n\sqrt n)$ |
| **Linear Attention** | 核映射 $\phi(Q)(\phi(K)^\top V)$ | $O(nd^2)$,递归无 KV |
| **SSM/Mamba** | 状态递归替代注意力 | O(1)/token,见 [Mamba 状态空间模型](./Mamba 状态空间模型.md) |

> [!note] online softmax 数值等价
> 分块累加时维护 running $(m,\ell)$,每次用 $e^{m^\text{old}-m^\text{new}}$ rescale,等价于全局减 max 的 softmax,既防溢出又无需落盘 $n\times n$ 矩阵。这是 FlashAttention 的数学核心。
