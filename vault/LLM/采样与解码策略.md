# 采样与解码策略

> [!abstract] 一句话
> 模型每步输出词表上的 logits,**解码策略决定怎么从中选下一个 token**——在"确定性/多样性"和"质量/合规"之间调。主线见 [大模型推理与部署](./大模型推理与部署.md) §VI.2。

---

## 1. 从 logits 到 token
$$z\in\mathbb{R}^V \xrightarrow{\text{softmax}(z/T)} p \xrightarrow{\text{截断/惩罚}} \tilde p \xrightarrow{\text{采样/argmax}} \text{token}$$

## 2. 核心旋钮

### 2.1 Temperature
$$p_i=\frac{e^{z_i/T}}{\sum_j e^{z_j/T}}$$
- $T\to0$:退化为 **greedy**(argmax),确定性最强。
- $T\to\infty$:趋近**均匀分布**,最随机。
- $T<1$ 锐化(更保守)、$T>1$ 平滑(更发散)。

### 2.2 Top-k
保留概率最高的 $k$ 个,重归一化后采样。硬截断尾部,但 $k$ 固定不自适应(平峰/尖峰一视同仁)。

### 2.3 Top-p(Nucleus)
$$V_p=\min\Big\{k\ \Big|\ \sum_{i=1}^k p_i\ge p\Big\}$$
取累积概率首次达 $p$ 的**最小前缀集**,集合大小**自适应**:分布尖锐时集合小、平坦时集合大。

### 2.4 Min-p
保留 $p_i\ge p_\text{min}\cdot\max_j p_j$ 的 token。按**峰值**自适应:模型很确定(峰高)时阈值高、候选少;不确定时放宽。低温高质量场景常优于 top-p。

### 2.5 重复惩罚
- **repetition penalty**:已出现 token 的 logit 除以 $\rho>1$。
- **frequency / presence penalty**(OpenAI 式):按出现**次数** / 是否出现**线性**减 logit。
抑制复读/啰嗦。

## 3. 采样顺序
典型(vLLM):**重复惩罚 → temperature → top-k → top-p → min-p → 采样**。顺序影响结果(先温度后截断 vs 反之)。

## 4. Beam Search
保留 $B$ 条最高累计对数概率的候选束,逐步扩展。适合**确定性强、有唯一最优**的任务(翻译/摘要);开放生成中易乏味、重复,LLM 对话**很少用**。

## 5. 约束 / 结构化解码(Guided Decoding)
要求输出严格 JSON / 正则 / 语法:把 schema 编译成 **FSM / 下推自动机**,每步只允许"合法后继 token",非法 token 的 logit 置 $-\infty$(掩码)。
- **Outlines**:正则→FSM,预编译转移表,每步 O(1) 取掩码。
- **xgrammar / llguidance**:CFG 上下文无关文法,处理嵌套,kernel 级加速。
- **Token healing**:修复 tokenizer 边界(避免把 `"` 与后续错切)。
> 与采样在 logits 层叠加;代价是掩码构建 + 词表级 gather。

## 6. 选型直觉
| 场景 | 推荐 |
|---|---|
| 确定性/代码/数学 | greedy 或低温 + 约束解码 |
| 创意写作 | T≈0.8 + top-p 0.9 / min-p |
| 结构化输出 | greedy/低温 + FSM 约束 |
| 防复读 | + repetition/frequency penalty |
