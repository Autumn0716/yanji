# 应用层

> [!NOTE]
> 原文几乎为空；以下按 408 计网常见考点搭的复习提纲，请用教材/课件填例子与报文格式。

## 定义

应用层是网络体系结构中**最靠近用户**的一层，定义进程间交换的报文语义与交互规则（协议）。

## 要点

### 两种应用架构
- **客户-服务器（C/S）**：服务器常在线、有固定地址；客户主动发起
- **P2P**：对等节点既是客户也是服务器（如部分文件分发）

### 高频协议（建议逐个补一页）
| 协议 | 作用 | 默认端口（常考） |
| --- | --- | --- |
| DNS | 域名 → IP | 53 |
| HTTP/HTTPS | Web | 80 / 443 |
| SMTP / POP3 / IMAP | 邮件发送/收取 | 25 / 110 / 143 |
| FTP | 文件传输（控制+数据连接） | 21 / 20（主动模式数据） |
| DHCP | 自动配置 IP 等 | 67/68 |

### 与运输层的关系
- 应用进程通过 **Socket** 使用 TCP/UDP
- 可靠传输、拥塞控制在运输层；应用层关心报文含义与会话流程

## 易错点
- DNS 既可用 UDP 也可在区传送等场景用 TCP（别只记「DNS=UDP」）
- HTTP 无状态；Cookie/Session 是应用侧补状态
- FTP 控制连接与数据连接要分开记
