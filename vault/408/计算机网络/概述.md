# 计算机网络概述

对应 **CN-1.1～CN-1.6**。[考纲拆分](../../../brain/research/408-syllabus/computer-networks.md)。

## 基本概念（CN-1.1～1.3）

- **定义**：自治系统互连、实现资源共享与数据通信
- **组成**：硬件（主机、结点、链路）+ 软件（协议栈）
- **功能**：数据通信、资源共享、分布式处理、提高可靠性等
- **分类**：按范围（PAN/LAN/MAN/WAN）、拓扑、交换方式、使用者等（原文未枚举 → 细节 `uncertain`）
- **性能指标**：速率、带宽、吞吐量、时延（发送/传播/处理/排队）、时延带宽积、RTT、利用率

## 体系结构（CN-1.4～1.6）

- **分层**：降低复杂度；每层协议独立
- **协议 / 接口 / 服务**：协议=对等层规则（语法语义同步）；服务=下层向上提供；接口/SAP 交接
- **OSI 七层** vs **TCP/IP**（四/五层常见讲法）：应用·运输·网络·网络接口；或应用·运输·网际·网络接口

| OSI | 典型功能 |
| --- | --- |
| 应用/表示/会话 | 常合并进 TCP/IP 应用层讨论 |
| 运输 | 端到端 |
| 网络 | 路由转发 |
| 数据链路 | 帧、接入 |
| 物理 | 比特传输 |
