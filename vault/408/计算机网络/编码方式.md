# 编码方式（线路编码）

> [!abstract] 一句话
> 用「何时跳变」区分几种经典编码；曼彻斯特类自带时钟，但带宽开销更大。

![编码波形对照](/vault/408/%E8%AE%A1%E7%AE%97%E6%9C%BA%E7%BD%91%E7%BB%9C/%E9%99%84%E4%BB%B6/Screenshot%202026-07-01%20at%2020-44-34.png)

## 对照表

| 编码 | 规则（课堂口诀） | 特点 |
| --- | --- | --- |
| **NRZ**（非归零） | **变则变**（电平随比特变） | 最简单；长串 0/1 难抽时钟 |
| **NRZI**（差分非归零） | **遇 1 才变** | 「懒启动」；仍可能长串 0 无跳变 |
| **曼彻斯特** | **码元内部总有跳转**；下一时刻遇变化才**再变**（体感像保持） | 自带同步；每位至少一跳 → 带宽约 2 倍 |
| **差分曼彻斯特** | **码元内部总有跳转**；下一时刻**遇 1 则变化**（体感像保持） | 同步性好；用「有无额外跳变」表 0/1 |

## 记忆抓手

- NRZ / NRZI：看**比特边界**怎么变
- 两种曼彻斯特：先保证**位中间跳**（抽时钟），再用「下一位要不要额外变」编码
- 考试常画波形：先标时钟中点，再按规则填高低电平
