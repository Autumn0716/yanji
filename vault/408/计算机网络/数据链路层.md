# 数据链路层

对应 **CN-3.1～CN-3.20**。[考纲拆分](../../../brain/research/408-syllabus/computer-networks.md)。

## 功能与组帧、差错（CN-3.1～3.4）

封装成帧、透明传输、差错控制、流量控制等。组帧：字符计数/填充、比特填充等。检错（奇偶、CRC）与纠错（海明等，具名 `uncertain`）。

## 可靠传输与滑动窗口（CN-3.5～3.8）

- 停止－等待
- **GBN**（后退 N 帧）：累计确认，重传窗口内
- **SR**（选择重传）：独立确认，接收方缓存

> from0to1 曾误作「滑轮窗口」——以「滑动窗口」为准。

## 介质访问控制（CN-3.9～3.11）

- 信道划分：FDM/TDM/WDM/CDM
- 随机访问：ALOHA、CSMA、**CSMA/CD**、**CSMA/CA**
- 轮询：令牌传递

## 局域网 / 广域网 / 设备（CN-3.12～3.20）

- 以太网与 IEEE 802.3；最短帧长与 CD
- IEEE 802.11；**VLAN**（2025 转载）
- 广域网概念；**PPP**；HDLC（from0to1，`uncertain`）
- **交换机**自学习/转发；网桥（from0to1，`uncertain`）
