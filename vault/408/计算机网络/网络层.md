# 网络层

对应 **CN-4.1～CN-4.25**。[考纲拆分](../../../brain/research/408-syllabus/computer-networks.md)。

## 功能（CN-4.1～4.4）

异构互联；**路由**（算路）vs **转发**（查表）；**SDN** 基本概念（控制/数据平面分离，2025）；拥塞控制（网络层视角）。

## 路由算法（CN-4.5～4.8）

静态/动态；**距离－向量**；**链路状态**；层次路由。

## IPv4 / IPv6（CN-4.9～4.14）

- IPv4 分组首部关键字段；分片
- 地址与 **NAT**；子网、掩码、**CIDR**、路由聚集；最长前缀匹配
- **ARP / DHCP / ICMP**
- IPv6 特点与地址形式

## 路由协议与组播、移动 IP（CN-4.15～4.23）

AS；域内/域间；**RIP / OSPF / BGP**；组播概念与地址；移动 IP 概念与通信过程。

## 设备（CN-4.24～4.25）

路由器组成；路由表与分组转发。

## 自检

- [ ] 能划分子网并写聚合
- [ ] 能对比 RIP/OSPF/BGP 层级
