# 数组

> [!abstract] 一句话
> 数组是下标随机访问的连续序列；C++ 里栈上自动期、堆上 `new[]/delete[]`；动态数组（如 vector）在此之上做扩容。

## 1. 初始化数组

```cpp
// 栈存储, 自动分配内存
int arr[5];
int nums[5] = {1, 2, 3, 4, 5};
// 堆存储, 需要手动释放
int *arr1 = new int[5];
int *nums1 = new int[5]{1, 2, 3, 4, 5};

// delete[] nums1;
// delete[] arr1;
// delete[] 按数组元素个数释放
```

### 栈 vs 堆

| | 栈 | 堆 |
| --- | --- | --- |
| 分配/回收 | 编译器自动，离作用域即毁 | `new/delete`（或智能指针）手动 |
| 生命周期 | 绑定作用域 | 可跨作用域，直到释放 |
| 速度 | 通常更快 | 更慢（空闲块/元数据） |
| 容量 | 较小，过大易栈溢出 | 更大，适合动态大小 |
| 风险 | 溢出 | 泄漏、悬空指针 |

**索引**本质上是相对首地址的**偏移量**。

### 扩容数组

```cpp
int *extend(int *nums, int size, int enlarge) {
  int *res = new int[size + enlarge];
  for (int i = 0; i < size; i++) {
    res[i] = nums[i];
  }
  delete[] nums;
  return res;
}
```

## 2. 列表（动态数组）

列表（list）可用 **动态数组（dynamic arrays）** 实现：继承数组随机访问优点，并在运行时扩容。

### 迭代器（iterator）

- STL 里遍历容器的通用工具，本质是对象
- 封装「当前位置 + 如何到下一元素」
- 常以指针思想实现

```cpp
nums.insert(nums.begin() + 3, 6);
// begin() 得到首元素迭代器；+3 指向索引 3
```

### 遍历

```cpp
// 索引遍历
int count = 0;
for (int i = 0; i < nums.size(); i++) {
  count += nums[i];
}

// 范围 for
int count2 = 0;
for (int num : nums) {
  count2 += num;
}
```

### 拼接

```cpp
vector<int> nums{1, 2, 3, 4, 5};
vector<int> nums1{6, 7, 8, 9, 10};
nums.insert(nums.end(), nums1.begin(), nums1.end());
```
