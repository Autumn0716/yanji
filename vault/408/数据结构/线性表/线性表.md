# 线性表

> [!abstract] 一句话
> 线性表是 **n 个相同类型数据元素** 构成的**有限序列**；实现上常见顺序表与链表。

## 定义

1. 线性表是由 n 个**数据元素**构成的有限序列（相同类型、有限、有序位置关系）

> [!NOTE]
> 数据元素由**数据项**组成（如学生元素含学号、姓名等项）。

## 顺序表要点

2. **二分查找**失败时：循环结束满足 `low = high + 1`（插入位置常取 `low`）

## 链表要点

3. 插入/删除时先保证 **前驱→next** 新连接建好，再改其它指针（防断链丢节点）
4. **带头结点的循环单链表** 不存在空指针（空表时头结点 `next` 指向自己）
5. **双链表** 已知结点插入/删除可达 O(1)；**单链表** 往往要先找前驱 → O(n)
6. 经典申请结点：`s = (LNode *)malloc(sizeof(LNode));`

## 补充对照

| | 顺序表 | 链表 |
| --- | --- | --- |
| 随机访问 | O(1) | O(n) |
| 插入删除（任意位置） | 要搬移，O(n) | 改指针；找点 O(n)/已知点 O(1) |
| 空间 | 连续，可能扩容 | 结点分散 + 指针域开销 |

## 知识点补全（追加）

### 基本操作（ADT 语义）

常见抽象操作（实现因存储而异）：

- `InitList` / `DestroyList` / `ClearList` / `ListEmpty` / `ListLength`
- `GetElem(L,i)` / `LocateElem(L,e)`
- `ListInsert(L,i,e)` / `ListDelete(L,i)` / 遍历

**位序**从 1 起算时与数组下标差 1，写题先统一约定。

### 顺序表补强

- 地址连续 ⇒ `a[i]` 随机访问 O(1)
- 第 i 位插入/删除平均移动约一半元素 ⇒ O(n)
- 动态顺序表扩容常用倍增，均摊插入 O(1)，最坏单次 O(n)

### 链表补强

- **单链表**：结点 `{data, next}`；头指针 vs 头结点
- **循环链表**：末结点 `next` 指头；空循环表头结点自环（上文已写）
- **双链表**：`prior/next`；已知结点插入删除 O(1)
- **静态链表**：数组模拟游标（考纲未单列 → `borderline`，了解即可）

时间：按位查找 O(n)；在**已知结点**处插入/删除指针改写 O(1)。
