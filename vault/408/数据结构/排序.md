# 排序

对应 **DS-7.1～DS-7.12**。[考纲拆分](../../../brain/research/408-syllabus/data-structures.md)。

## 基本概念（DS-7.1）

稳定性；内部/外部排序；排序码；「趟」。

## 内部排序一览（DS-7.2～7.10）

| id | 算法 | 稳定？ | 时间（典型） | 空间 | 要点 |
| --- | --- | --- | --- | --- | --- |
| 7.2 | 直接插入 | 是 | O(n²) | O(1) | 适基本有序 |
| 7.3 | 折半插入 | 是 | 比较↓ 移动仍 O(n²) | O(1) | 有序表折半定位 |
| 7.4 | 起泡 | 是 | O(n²) | O(1) | 可提前结束 |
| 7.5 | 简单选择 | **否** | O(n²) | O(1) | 交换少 |
| 7.6 | 希尔 | 否 | 依赖增量 | O(1) | 分组插入 |
| 7.7 | 快速 | 否 | 平均 n log n，最坏 n² | 递归栈 | 枢轴划分 |
| 7.8 | 堆 | 否 | O(n log n) | O(1) | 建堆+下沉；见堆应用 |
| 7.9 | 二路归并 | 是 | O(n log n) | O(n) | 分治合并 |
| 7.10 | 基数 | 是 | O(d(n+r)) | O(n+r) | 分配收集 |

## 外部排序（DS-7.11）

生成初始归并段 → 多路平衡归并；败者树降比较次数；置换－选择增大初始段（具名技术 `uncertain`）。

## 分析与应用（DS-7.12）

- 要稳定：插入/起泡/归并/基数
- 要原地且 n log n：堆排
- 平均很快：快排（防劣化：随机枢轴/三数取中）
- 基本有序：直接插入
