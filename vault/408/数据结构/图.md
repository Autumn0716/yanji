# 图

对应 **DS-5.1～DS-5.10**（源文件章节号重号为「四、图」）。[考纲拆分](../../../brain/research/408-syllabus/data-structures.md)。

## 基本概念（DS-5.1）

有向/无向、简单图、完全图、子图、度（入/出）、路径/回路、连通/强连通分量、网（带权）、生成树/生成森林。

## 存储（DS-5.2～5.4）

| 结构 | 要点 |
| --- | --- |
| 邻接矩阵 | O(n²)；稠密图；度好算 |
| 邻接表 | 稀疏图；出边易、入边需逆邻接表 |
| 十字链表 | 有向图，便处理入/出边 |
| 邻接多重表 | 无向图，便处理边 |

## 遍历（DS-5.5～5.6）

- **DFS**：栈/递归；生成森林
- **BFS**：队列；无权最短边数路径

时间与存储结构相关：邻接矩阵 O(n²)，邻接表 O(n+e)。

## 应用（DS-5.7～5.10）

### 最小（代价）生成树

Prim（加点）、Kruskal（加边）；原文未点名算法 → 具名标 `uncertain`，但仍为常规必会。

### 最短路径

Dijkstra（非负权）、Floyd（任意两点）；负权/Bellman-Ford → `borderline`。

### 拓扑排序

AOV 网；入度零顶点；可判环。

### 关键路径

AOE 网；事件最早/最迟；关键活动与关键路径。
