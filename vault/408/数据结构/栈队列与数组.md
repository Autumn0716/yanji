# 栈、队列和数组

对应 **DS-3.1～DS-3.6**。[考纲拆分](../../../brain/research/408-syllabus/data-structures.md)。

## 栈（LIFO）

- 仅在栈顶插入/删除；溢出/下溢
- **顺序栈**：数组 + `top`；两栈共享空间（从两端向中间长）可提高利用率
- **链栈**：本质是头插/头删的单链表

**应用（题型 uncertain）**：括号匹配、表达式求值（中缀↔后缀）、递归消除、函数调用栈。

## 队列（FIFO）

- 队尾入、队头出
- **顺序队列**假溢出 → **循环队列**：`(rear+1)%MaxSize == front` 判满（牺牲一单元）或另用 `size`/`tag`
- **链队**：队头指针删、队尾指针增

**应用**：层序遍历、缓冲区、排队模型。

> 「双端队列」原文未写 → `borderline`。

## 多维数组的存储（DS-3.4）

- 行优先：`Loc(i,j) = Loc(0,0) + (i×n + j)×L`（下标从 0、n 列）
- 列优先：先变行号
- 与 [数组](./线性表/数组.md) 互补：彼处偏 C++ 实现，此处偏地址映射

## 特殊矩阵压缩（DS-3.5）

| 类型 | 思想 |
| --- | --- |
| 对称 | 只存下/上三角 |
| 三角 | 含对角的一侧 + 常数区 |
| 对角/带状 | 按对角线存放 |
| 稀疏 | 三元组 `(i,j,val)` 或十字链表 |
