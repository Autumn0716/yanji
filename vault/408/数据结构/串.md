KMP算法:
next数组与nextval数组;
next数组表示第j个元素不匹配时需要把当前主串对应元素`Str[i]`与模式串匹配的第`next[j]`个位置匹配

因此`next[j]`=j-右滑位数
也`next[j]`=j-\[(j-1)-PM\(j-1)]=PM(j-1)+1
PM也就是模式匹配长度(即最长公共前后缀长度)

### 浅显易懂法:
```python
def next(patt):
	next=[0] #初始化next数组
	prefix_len=0 #当前公共前后缀的长度
	i=1
	while(i<patt.len()){
		if(patt[prefix_len]==patt[i]){
		++i
		++prefix_len
		next.append(prefix_len)
		}
		else:
			if(prefix_len==0){
			next.append(0)
			++i
			}
			else{prefix_len=next[prefix_len-1]
			}
	return next
	}
```
