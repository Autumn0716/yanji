# KMP算法:
next数组与nextval数组;
next数组表示第j个元素不匹配时需要把当前主串对应元素`Str[i]`与模式串匹配的第`next[j]`个位置匹配

因此`next[j]`=j-右滑位数
也`next[j]`=j-\[(j-1)-PM\(j-1)]=PM(j-1)+1
PM也就是模式匹配长度(即最长公共前后缀长度)

### 浅显易懂法:
```python
def next(patt):
	next=[0] #初始化next数组
	prefix_len=0 #当前公共前后缀的长度
	i=1
	while(i<patt.len()){
		if(patt[prefix_len]==patt[i]){
		++i
		++prefix_len
		next.append(prefix_len)
		}
		else:
			if(prefix_len==0){
			next.append(0)
			++i
			}
			else{prefix_len=next[prefix_len-1]
			}
	return next
	}
```

KMP基本算法如下:

next
看j-1是否与nextj-1相等,是则+1,不是则回溯选值
```c
void next(SString str,int next[]){
	int i=1;//i=j+1
	int j=0;
	next[1]=0;
	while(i<str.lenth){
	
		if(j==0||str[i]==str[j]){
			++i;
			++j;
			next[i]=j;	
		}
		else
			j=next[j]
			
	}
}
```

nextval(优化版本)
核心意图是:对next优化
next如果与j相等的话就尝试回溯跳跃,不相等就保留next值
直至最简,几乎不能被压缩

```c
```c
void nextval(SString str,int next[]){
	int i=1;//i=j+1
	int j=0;
	nextval[1]=0;
	while(i<str.lenth){
	
		if(j==0||str[i]==str[j]){
			++i;
			++j;
			if(str[i]!=str[j]) nextval[i]=j;
			else nextval[i]=nextval[j]	
		}
		else
			j=nextval[j]
			
	}
}
