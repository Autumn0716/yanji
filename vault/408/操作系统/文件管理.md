# 文件管理

对应 **OS-4.1～OS-4.16**。[考纲拆分](../../../brain/research/408-syllabus/operating-systems.md)。

## 文件（OS-4.1～4.7）

- 文件：具名数据集合；属性（名、类型、位置、大小、保护等）
- **inode / 元数据**：索引结点存属性与磁盘块指针；目录项常含文件名+inode 号
- **操作**：创建、删除、打开、关闭、读、写；打开文件表
- **保护**：访问类型；口令/ACL/能力等（教材点）
- **共享**（from0to1）：基于 inode 的共享等 → `uncertain` 并存
- **逻辑结构**：顺序、索引、索引顺序文件
- **物理结构**：连续、链接、索引（单级/多级/混合）分配



> 内存索引结点特有的有一个: **访问计数值**

### 索引顺序文件:

**一级索引平均查找次数:&#x20;**√n

**二级索引平均查找次数:&#x20;**$$\frac{3\sqrt[3]{n}}{2}$$

**通用k级索引平均查找次数:&#x20;**$$\frac{k+1\sqrt[k+1]{n}}{2}$$

### 逻辑结构:

| 类型 | 特点 | 优点 | 缺点 | 例子 |
| - | - | - | - | - |
| 流式文件 | 文件是无结构的字节序列,没有记录边界 | 简单灵活,操作系统不关心内容 | 用户自己解析结构 | Unix/Linux的普通文件,文本文件 |
| 记录式文件 | 文件由一组固定长度或者可变长度的记录组成 | 适合数据库 批量处理 | 灵活性差 | COBOL文件 |
| 顺序文件 | 记录按顺序排列, 只能从头到尾访问 | 实现简单,适合批量读写 | 随机访问慢 | 日志文件 |
| 索引文件 | 维护一个索引表,记录关键字->物理位置的映射 | 随机访问快 | 索引表占额外空间 | 数据库索引文件 |
| 索引顺序文件 | 索引+顺序结合,索引指向一个块.块内顺序存储 | 兼顾顺序访问和随机访问 | 实现复杂 | IBM索引顺序存取(ISAM) |
| 树形结构 | 数据按B+树组织 | 查找效率高 | 实现复杂 | NTFS目录索引 |

### 物理结构:

| 类型 | 存储方式 | 优点 | 缺点 | 使用场景 |
| - | - | - | - | - |
| 连续分配 | 文件占用磁盘上连续块 | 顺序访问快实现简单 | 产生外部碎片,文件难扩展 | 早期OS.CD_ROM |
| 链接分配 | 每个块存一个指向下一个块的指针 | 无外部碎片,文件可动态扩展 | 随机访问慢,指针占用空间,一个块丢失整个文件 | 早起FAT |
| 索引分配 | 文件有一个索引块,存所有数据块的地址 | 支持随机访问,无外部碎片 | 索引块占用空间,小文件浪费 | Unix inode,NTFS |
| FAT | 用一个FAT表存储所有文件的连接关系 | 链接信息集中存放,可靠性提高 | FAT表占用空间,大文件访问慢 | FAT |
| 混合索引 | 小文件用块,大文件用间接块 | 兼顾小文件和大文件 | 实现复杂 | Unix/Linux inode |

## 目录（OS-4.8～4.11）

- 目录项；绝对/相对路径
- **树形目录**；单级/两级/无环图（from0to1 更细）作对照
- 目录操作：检索、创建、删除子目录等
- **硬链接**：共享 inode，链接计数；通常不可跨文件系统指目录
- **软链接**：独立 inode，存路径字符串

## 文件系统实现（OS-4.12～4.16）

- **layout**：外存上引导块/超级块/inode 区/数据区等；内存中超级块缓存、inode 缓存、打开文件表
- **空闲空间**：空闲表、空闲链表、位图、成组链接
- **VFS**：统一文件接口，屏蔽具体 FS
- **mount**：把 FS 挂到目录树挂载点
- from0to1「层次/目录实现/文件实现」三分与上对照复习
