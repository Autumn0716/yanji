# USB（Universal Serial Bus）

> [!abstract] 一句话
> **是的——USB 就是「规范/统一的外设 I/O 接口」**：一套电气 + 协议 + 连接器标准，让不同厂家设备能即插即用地接到主机。

溯源摘录见 [USB Wikipedia 备忘](../../../../brain/external-sources/usb-wikipedia.md)。

与计组 [输入输出系统](输入输出.md) 的关系：教材里的「I/O 接口」是抽象部件；**USB 是工业界落地的一种高速串行总线标准**（外加集线器拓扑、设备类、供电规范）。

---

## 1. 它算不算「规范 I/O / 统一接口」？

**算。** 设计目标就是：

- **统一连接器与协议**，少造专用口
- **即插即用 / 热插拔**，少折腾 IRQ、I/O 端口、DMA 通道等手工配置
- **同一根线兼顾数据（以及后来的供电）**

在 408 语境里可记：

| 层次 | 例子 |
| --- | --- |
| 控制方式（抽象） | 查询 / 中断 / DMA / 通道 |
| 接口标准（具体） | USB、PCIe、SATA、… |

USB 主机侧通常由 **USB 主机控制器**完成枚举、调度；对 CPU 来说更像「通过控制器做 I/O」，设备侧常配合中断/DMA 类机制，而不是让你手写并口时序。

---

## 2. 最初用来做什么？

约 **1996**（USB 1.0；**1.1/1998** 才广泛落地）：

- **统一 PC 外设连接**，替代串口、并口、游戏口、PS/2/ADB 等「一设备一口」
- 典型早期用途：**键盘、鼠标、打印机、扫描仪、相机、U 盘、早期手机数据线**
- 卖点：热插拔、自配置、可给小设备供电、成本可控

当时带宽按今天看不高（Low 1.5 / Full 12 Mbit/s），定位是**桌边外设总线**，不是机房骨干网。

---

## 3. 现在主要用来做什么？

在「外设总线」之上，角色扩成「万能口」：

| 用途 | 说明 |
| --- | --- |
| 数据 | 键鼠、U 盘、移动硬盘、网卡、音频、摄像头… |
| **供电/充电** | 手机、笔记本供电；**USB Power Delivery (PD)** 可谈高压大功率 |
| **显示/视频** | 经 USB-C **Alternate Mode** 或 USB4 **隧道**跑 DisplayPort 等 |
| **扩展坞** | 一缆扩展网口、多屏、存储 |
| 主机互连 | USB4 支持 host-to-host 等能力（视实现） |

口诀：**早期 = 统一外设数据口；现在 = 数据 + 电 +（常经 C 口）视频/扩展。**

## 4. 现在有哪些主要「规范」？（易混：速率代际 ≠ 插头形状）

### 4.1 数据总线代际（USB-IF）

| 规范 | 大致年代 | 量级速率（信令） | 备注 |
| --- | --- | --- | --- |
| USB 1.0 / **1.1** | 1996 / 1998 | 1.5 / 12 Mbit/s | 真正普及从 1.1 |
| **USB 2.0** | 2000 | **480 Mbit/s** High-Speed | 长期「默认 USB」 |
| **USB 3.0 → 3.1 → 3.2** | 2008–2017 | 5 / 10 / 最高约 **20 Gbit/s**（双通道+C） | 命名多次改，现多按 **Gbps** 营销 |
| **USB4** | 2019 | 20 / **40 Gbit/s** | 可隧道 DP、PCIe；基于 TB3 思路 |
| **USB4 Version 2.0** | 2022 | 对称约 **80 Gbit/s**（另有非对称更高显示向模式） | 仍属 USB4 族 |

> [!WARNING]
> 包装上的「USB 10Gbps / 40Gbps」比「USB 3.2 Gen2×1」好记；**插头写着 USB-C 不代表一定是 USB4 全速**。

### 4.2 连接器与供电（常并列考察）

| 规范族 | 管什么 |
| --- | --- |
| **USB Type-C（USB-C）** | 可正反插的物理连接器；USB4 **要求**用 C；还可承载非 USB 协议（Alt Mode） |
| **USB Power Delivery (PD)** | 协商电压电流；近年可到很高瓦数（视 PD 修订，如 EPR 档） |
| Battery Charging 等 | 更早的充电相关补充规范 |
| 设备类（Class） | HID、Mass Storage、Audio、Video… 决定主机加载哪类驱动 |

### 4.3 和计组课的对应

- **拓扑**：分层星型（主机 — hub — 设备），不是任意设备互连对等网  
- **主机轮询/调度**为主（相对早期 FireWire 等更「主从」）  
- **热插拔 + 枚举**：接入后分配地址、读描述符、加载驱动——对应「即插即用」
