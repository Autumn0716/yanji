# 函数调用与栈帧

> [!abstract] 一句话
> 每次调用在栈上建一个 **stack frame**：存返回地址、保存的 EBP、局部变量与传参；`call`/`ret`（或 `enter`/`leave`）维护它。

## 高级语言视角

函数的栈帧（stack frame）：

- 保存函数体内的**局部变量**
- 保存**调用相关信息**（返回地址、旧帧指针等）

关键指令：`call` / `ret`

## 栈与指针

- 常见约定：**栈底高地址，栈顶低地址**（向低地址增长）
- x86-32 常以 **4 字节**为栈操作单位
- **EBP**：当前帧基指针（frame pointer）
- **ESP**：栈顶指针
- 一对 EBP/ESP 刻画一个栈帧
- `push` / `pop` 访问栈顶；`mov` 可按偏移访问帧内；`sub`/`add` 调整 ESP

![调用序列](/vault/408/%E8%AE%A1%E7%BB%84/%E6%8C%87%E4%BB%A4%E7%BB%93%E6%9E%84/%E9%99%84%E4%BB%B6/Screenshot%202026-07-05%20at%2015-53-05.png)

### `enter` ≈ 建立帧（调用序）

典型等价直觉：

```text
push ebp
mov  ebp, esp
; 再 sub esp, <局部变量空间>
```

> 笔记原话：`push ebp` 时 esp 会变化，所以随后 `mov ebp, esp`。

![leave](/vault/408/%E8%AE%A1%E7%BB%84/%E6%8C%87%E4%BB%A4%E7%BB%93%E6%9E%84/%E9%99%84%E4%BB%B6/Screenshot%202026-07-05%20at%2015-54-59.png)

### `leave` ≈ 拆除帧（返回前）

```text
mov esp, ebp
pop ebp
```

然后通常再 `ret`。

## 栈帧里有什么

![栈帧内容](/vault/408/%E8%AE%A1%E7%BB%84/%E6%8C%87%E4%BB%A4%E7%BB%93%E6%9E%84/%E9%99%84%E4%BB%B6/Screenshot%202026-07-05%20at%2018-47-22.png)

- **靠近栈底方向**：保存的 EBP、返回地址等
- `ebp-4` 常是「靠近栈底的第一个局部」一侧（具体看约定）
- **栈帧顶部（低地址侧）附近**：往往是返回地址相关布局（结合图记）
- 参数列表：**越靠前的参数离栈顶越近**（倒着压栈的常见 cdecl 印象）
- 实践中常把栈帧大小对齐到 **16B** 整数倍（ABI）
