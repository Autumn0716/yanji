# 机器语言（x86 视角）

> [!abstract] 一句话
> 机器/汇编层：PC（x86 常称 **IP/EIP/RIP**）指向下一条指令；内存操作数用 `[]`，寄存器与立即数不用。

## 寻址书写

- x86 中 PC（Program Counter）通常叫 **IP / Instruction Pointer**
- **主存地址**需要中括号：`jmp [999]`
- **寄存器、常数**不需要中括号

## 选择语句（分支）

### 条件转移 `jxxx`

先比较，再跳转：

```text
cmp a, b
je  addr   ; 相等
jne addr   ; 不相等
jg  addr   ; a > b（有符号）
jge addr   ; a >= b
jl  addr   ; a < b
jle addr   ; a <= b
```

> [!TIP]
> 无符号比较常用 `ja/jb` 等；考试看清有无符号。

## 循环语句

### `loop` 指令

- **默认使用 `ecx`（或 `rcx`）作计数器**

```text
mov ecx, 500
Looptop:
  ; ... 循环体 ...
  loop Looptop   ; ecx--, 若 ecx!=0 则跳回 Looptop
```

- `loopnz` / `loopne`：计数减一后，还要求 **ZF=0** 才继续循环
