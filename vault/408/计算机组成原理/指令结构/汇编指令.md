# 汇编指令（x86）

> [!abstract] 一句话
> 先认准操作数在**寄存器 / 主存 / 立即数**；再记 Intel（`mov d,s`）与 AT&T（`mov s,d` + `%`/`$`）两套写法。

指令操作数可能来自：**寄存器**、**主存**、**立即数（指令中）**。

## AT&T 格式（Unix/Linux）

![AT&T vs Intel](/vault/408/%E8%AE%A1%E7%BB%84/%E6%8C%87%E4%BB%A4%E7%BB%93%E6%9E%84/%E9%99%84%E4%BB%B6/Screenshot%202026-07-05%20at%2002-05-10.png)

要点：

- 操作数方向常与 Intel **相反**（源在前）
- 偏移量写在小括号前
- 宽度后缀：`b`/`w`/`l`（byte/word/dword）
- 寄存器前加 `%`，立即数前加 `$`
