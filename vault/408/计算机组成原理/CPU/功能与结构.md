## 取指（必背通路）

```text
(PC) → MAR
1 → R                 ; 发读命令（教材符号因书而异）
M(MAR) → MDR
(MDR) → IR
OP(IR) → 微操作信号发生器 / 译码
(PC)+1 → PC           ; 或 +指令字长
```

记忆：**PC 给出地址 → 主存读出指令 → 进 IR → PC 指向下一条**。
