# 流水线与异常

对应 **CO-5.5～CO-5.9**（CPU 章后半）。结构/取指见 [功能与结构](功能与结构.md)；微程序见 [微程序控制器](微程序控制器.md)。

## 异常和中断（CO-5.5）

- **异常**：指令执行中同步事件（故障/陷阱等）
- **中断（外中断 / 硬中断）**：外设等异步事件
- **软中断（软件中断 / 内中断）**：执行指令主动引发（如 `INT`、陷阱/`syscall`），属同步；典型用途含系统调用、断点
- 检测与响应：关中断/开中断、向量、优先级；**用户态→内核态由硬件完成**（改 PSW/态位）；**中断向量表（数组）**按下标最快取 ISR 入口，保障瞬时性；现场保护见 [I/O 中断](../输入输出/输入输出.md)；模式见 [操作系统概述·CPU 运行模式](../../操作系统/概述.md)

> 408 答题优先用「外中断 vs 异常/陷入」；「软中断」多指内中断，不是 Linux softirq。

## 指令流水线（CO-5.6～5.8）

- 基本概念与实现（如取指-译码-执行-访存-写回直觉）

- **冒险**：结构、数据、控制；前递/气泡/分支处理
- 超标量、动态流水线：多发射与动态调度概念级
