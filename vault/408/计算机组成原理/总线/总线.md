# 总线

> [!abstract] 一句话
> 总线是各部件共享的互连通路；按功能拆成主存总线、I/O 总线、DMA 等，用多总线减轻争用。

## 单总线

- 所有部件挂在同一组总线上（CPU、主存、I/O）
- 实现简单，但**争用严重**，速度受最慢设备拖累

## 双总线

### 主存总线

- 连接 **CPU — 主存 — 通道**
- **通道**对 I/O 设备统一管理；**通道程序放在主存**中（CPU 启动后由通道执行）

### I/O 总线

- 连接通道（或 I/O 处理器）与外设，减轻主存总线压力

## 三总线

在双总线基础上再加：

| 总线 | 作用 |
| --- | --- |
| 主存总线 | CPU ↔ 主存 |
| I/O 总线 | I/O 设备通路 |
| **DMA 总线** | 外设直接访存，不经 CPU 搬运大批数据 |

## 四总线（带桥）

课堂图示：

![四总线与桥接器示意](/vault/408/%E8%AE%A1%E7%BB%84/%E6%80%BB%E7%BA%BF/%E9%99%84%E4%BB%B6/Screenshot%202026-07-11%20at%2016-15-12.png)


常见分层直觉（名称因教材而异）：

- **CPU 总线**（最快）：CPU 内核 / Cache 侧
- **系统总线 / 高速总线**：连接主存、图形等高速部件
- **扩充总线**：接较慢外设
- **桥接器（Bridge）**：速率不同的总线之间做协议/时钟域转换
