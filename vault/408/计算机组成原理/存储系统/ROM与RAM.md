# ROM 与 RAM

> [!abstract] 一句话
> **RAM 易失、可随机读写**；**ROM 非易失**，按可写次数分成 MROM→PROM→EPROM/EEPROM→Flash；主存扩展还常考双端口与多体交叉。

## 易失性

- **RAM**：易失
- **ROM**：非易失

## 各种 ROM

| 类型 | 全称要点 | 可改性 |
| --- | --- | --- |
| **MROM** | Mask ROM 掩模 | 出厂写死，**任何人不可改**；密度高、灵活差、周期长 |
| **PROM** | Programmable | **写一次**后不可改 |
| **EPROM** | Erasable Programmable | **可多次**改 |
| **UVEPROM** | 紫外线擦除 | 紫外照射约 8–10 分钟擦除全部 |
| **EEPROM** | Electrically Erasable | **电擦除**，可按字擦 |
| **Flash** | 闪存 | **快速多次重写**；通常先擦后写 → **写比读慢**；位密度常高于 RAM |
| **SSD** | 控制单元 + Flash 芯片 | 快、功耗低、价高；手机辅存亦多用 Flash |

### BIOS

- 主板上的 BIOS 芯片：自举装入程序，引导操作系统
- 实质上 BIOS 内容也映射在**主存地址空间**一侧（固件视角）

## 双端口 RAM 和多模块存储器

### 双端口 RAM

- 目的：优化**多核/多主设备**同时访问同一主存
- 两组独立的数据/地址/控制线

同一地址单元冲突：

| 两端口操作 | 结果 |
| --- | --- |
| 不同地址 | 可同时存取 |
| 同时读同一地址 | 一般允许 |
| 同时写同一地址 | **非法** |
| 一边读一边写同一地址 | **读出可能错误** |

### 多体并行存储器

#### 高位交叉编址

- 例：全部 32 / 高位 2 → 体号在高位：0, 8, 16, 24… 这类分布（按题面画）

#### 低位交叉编址

- 连续地址落在不同体：0,1,2,3,4… → 更易并行取连续字

记录**读取时间**与**等待时间**（流水式多体访问）。

## 位扩展与字扩展

- **位扩展**：扩展数据总线宽度。例：8 片 1 位芯片 → 8 位数据
- **字扩展**：地址空间扩大（CPU 地址线有富余）
  - **线选法**：n 条线 → n 个片选
  - **译码片选**：n 条线 → \(2^n\) 个片选
