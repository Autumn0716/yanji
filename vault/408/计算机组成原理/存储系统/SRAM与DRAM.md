# SRAM 与 DRAM

> [!abstract] 一句话
> **SRAM**=触发器，快、贵、密低，多用于 Cache；**DRAM**=电容，要刷新，密高价低，多用于主存；**都易失**。

## 基本区别

| | SRAM | DRAM |
| --- | --- | --- |
| 存储原理 | 双稳态触发器 | 栅极电容（电荷会漏） |
| 读出 | **非破坏性**，无需重写 | **破坏性**，读后需重写 |
| 速度 | 更快 | 较慢 |
| 成本/密度 | 高成本、低密度 | 低成本、高集成度 |
| 典型用途 | Cache | 主存 |
| 地址 | 行列可同时给（位数相对少） | **行列分次送达**（复用地址线） |
| 易失性 | 易失 | 易失 |

![SRAM/DRAM 对比](附件/Screenshot%202026-07-01%20at%2021-18-44.png)

> 双稳态通常需要更复杂的管脚/线（笔记：双稳态就需要 2 根数据线等）。

## DRAM 的刷新

1. **多久刷新？** 数量级常考约 **2ms** 内整片扫一遍（以题面为准）
2. **每次刷新多少？** 通常按**行**：一行有 \(2^{10}=1024\) 之类单元时，行选通可大幅减少选通线（\(2^{20}\to 2^{11}\) 量级的直觉）

![刷新一行](附件/Screenshot%202026-07-01%20at%2021-28-18.png)

3. **如何刷新？** 硬件支持：读出一行再写回，占用一次读写周期
4. **何时刷新？** 分散刷新 / 集中刷新 / 异步刷新

![刷新时机](附件/Screenshot%202026-07-01%20at%2021-34-52%201.png)

### 地址送达

![行列分次](附件/Screenshot%202026-07-01%20at%2021-36-55.png)

- SRAM 集成度低、地址位少 → 方便**同时**送行列
- DRAM 地址位多 → **地址线复用**，地址线数目大约可减半
- 现代主存多为 **SDRAM** 一代代演进
